# 📸 MediaManager

**你的照片没有丢，只是再也想不起来了。**

三年前那趟旅行、猫小时候的样子、第一次剪完的片子——它们都还在硬盘里，只是躺在某个想不起来的文件夹第 47 页。
MediaManager 做的事很简单：把 C 盘、D 盘、移动硬盘里的图片、视频、音频、文档、压缩包收进同一个库，
然后**每次打开，随机推给你一批你很久没看过的**。

## 它解决的是三件很具体的事

### 1. 你不是没有照片，你是想不起来看

硬盘里躺着几万张图，谁有耐心一个个文件夹翻？
「发现」页每次从你的库里**随机挑一批你还没细看的**推到你面前——按 `R` 再换一批，永远不知道下一张是什么。

这件事没什么技术含量，但它是这个软件唯一的目的：**让旧照片重新出现在你眼前。**

### 2. 你不是不想整理，是它们散在五个盘里

手机导出的、相机卡的、移动硬盘备份的、微信存下来的——以前要开十几个资源管理器窗口对照。
现在一个库：**一个搜索框、一次筛选、一次批量改名/导出**，跨盘一起管。

拔掉移动硬盘不会崩，插回来能自己找回路径。

### 3. 你不是不敢删，是删了怕后悔

误删先进回收站，一键撤销。
收藏、分类、标签每天自动备份，保留最近 7 个时间点——**整个库能退回任何一个节点**，恢复前还会先把当前状态存一份，坏节点一律拒绝。

## 它还顺手做了这些（但别指望它替代专业软件）

- 图片轻编辑：裁剪、调色、文字、马赛克、水印。**编辑原图永远生成 `_edited` 副本，原图一个字节不动。**
- 视频播放：内置 LibVLC，倍速、全屏、播完行为可选。
- 80 种格式入库：图片 13 / 视频 17 / 音频 15 / 文档 25 / 压缩包 10。
- 单键操作：`R` 换一批、`F` 收藏、`1`~`5` 打星，**中文输入法下也照常生效**。
- 插件：官方没做的小需求，自己写一个丢进 `plugins` 文件夹。

> 它**不是**网盘（不上传任何东西），**也不是**修图软件（编辑器只是顺手做的）。如果你在找 Snapseed 或 PotPlayer，它们更专业。

# v1.4.7 — 桌面图标不再每次发版就失效

桌面图标以后不会再因为重新打包而打不开了——程序启动时会自己把指错的图标接回来，设置里也多了按钮可以手动创建或修复；另外修掉了更新提示里「还有 N 条改动」把测试项也算成改动的问题。

## 桌面图标不再失效

以前每次重新发布，我都会先把旧的运行目录整个移走再重建，而快捷方式里存的是绝对路径——路径一没，双击图标就报「找不到项目」，只能手工重建。

- 设置 → 系统集成 新增「桌面图标」卡片，按钮跟着实际状态变：桌面上没有时是「创建桌面图标」，指向当前程序时是「更新桌面图标」，指向已删除的旧路径时是「修复桌面图标」并显示那个失效路径。
- 程序启动时自动看一眼：只处理目标文件名是 `MediaManager.App.exe` 的快捷方式，发现它指向的程序已经不在了，就悄悄改成现在这个位置。
- 桌面上别人的快捷方式一个字节都不碰，不改名、不删除；写不进去（只读桌面、被安全软件拦）只当这次没成功，不影响别的功能。

## 更新提示的数字改对了

v1.4.6 的提示底部写着「另外还有 7 条改动」，但多出来的那些其实是「验证」小节里的测试项——点「查看完整说明」看到的是测试报告，不是功能。

原因是更新说明里的所有列表项都被当成了「改动」。现在只统计第一组要点，遇到新小节就停；只有第一组本身超过 5 条才会出现「还有 N 条」。

# v1.4.0 — 私密空间、日记、极简模式

这一版加了三个「新东西」，都是单软件内的深化，不再分简易版 / 标准版两个包。

## 🔒 私密空间（独立窗口版）

左边导航多了「🔒 私密空间」，也可以按 `Ctrl+L` 开关。它是一个**独立的窗口**，
和主界面并排摆着互不干扰，界面和主界面差不多：搜索、类型筛选（图片/视频/音频/文档/压缩包）、
缩略图大小滑块、双击打开对应查看器都齐全。

**不设密码，这是刻意的**：它是一个「藏起来」的空间（类似 Steam 隐私库），
挡的是家人、同事随手翻，不是取证 —— 文件被移动到数据目录下的 `Vault` 文件夹（目录设隐藏），
数据库里打 `IsPrivate` 标记，主网格、搜索、文件夹、标签、分类、收藏统计、最近查看、发现页 —— 全部查不到。
密码忘了不会丢数据这种问题根本不存在，真要找，打开「显示隐藏文件」就能看到 `Vault` 目录。

怎么把文件放进去（三种方式都行）：

- 主界面选中文件 → 右键「🔒 移入私密空间」
- **直接把文件拖进私密空间窗口**（从主界面或资源管理器拖都行）
- 私密空间窗口里点「＋ 导入文件」从别处选文件

移出同样三种方式（右键菜单 / 拖出会还原到原位置）。移入时保留原始路径记录，
移出时文件回到原位；私密项的缩略图单独存 `Vault/Thumbs`，不进公共缓存；
扫描器整目录跳过 `Vault`；「文件丢失」检查不碰私密项。
窗口 5 分钟无操作会自动关掉并上锁，下次打开重新点一下就好。

### 分区：东西多了也找得到

窗口左侧是一列分区，默认有「全部 / ⭐ 收藏 / 未分区」，下面可以自己建任意多个
（「截图」「聊天记录」「别人送的」……）。三个固定分组不能改名删除，自定义分区右键可重命名 / 删除。

- **怎么归类**：选中文件 → 拖到左侧分区名上；或右键 →「📁 放进分区」勾选
- **删分区不删文件**：分区只是盒子，盒子扔了文件还在（回到「未分区」）
- 每个分区后面显示文件数，一眼看到哪堆最多
- 分区名只见于这个窗口 —— 主界面侧栏不会露出任何分区名和数量

### 该有的功能都有

搜索、类型筛选（图片/视频/音频/文档/压缩包）、**排序**（最新/最早/文件名/大小/修改时间）、
**收藏**（右键 ⭐，只看收藏）、缩略图大小、多选（Ctrl / Shift）、双击打开对应查看器、
**重命名文件**（F2，扩展名锁死防止改坏）、**另存副本**（导出到别处，原件不动）、
打开所在位置、删除到回收站。右侧网格也支持把文件拖到左侧分区。


## 📔 日记

左边导航「📔 日记」打开独立窗口，左边日历右边回忆，类似发说说的感觉。

- **日历视图**：有内容的日期下面有个小圆点，点一下就看那天的回忆；`今天` 一键跳回。
- **一天可以写多篇**，每条能挂多个图片/视频。
- **编辑 / 删除**：卡片右上角。删日记不会删照片文件。
- **怎么加照片**：主界面选中 → 右键「📔 写进日记」；编辑窗里点「从媒体库选择」
  会开一个**独立窗口**，可以反复勾选、分批加入，选完不用重开；拖外部文件进来也能加，
  遇到不在媒体库里的文件会按下面的导入策略处理。
- 心情（emoji 可留空）、标题（可留空）、正文（可留空，只要有照片）。

日记只存在你自己的库里（`DiaryEntry` / `DiaryMedia` 两张表），没有任何联网。

## 📥 外部文件导入不再「自作主张」

把一个不属于任何媒体文件夹的文件拖进来 / 加进日记时，会**先弹窗问你**怎么办：

1. **复制到导入文件夹**（默认推荐）：复制一份到 `图片\MediaManager`，
   原文件原地不动；文件夹位置可以在 设置 → 媒体库 → 「外部文件导入」 里改。
2. **加入所在文件夹**：把文件所在目录注册为媒体文件夹。

勾上「记住我的选择」以后不再问，随时可以去设置里改回来。

## 🪟 弹出的窗口不再跟着主界面一起缩

以前主界面一最小化，图片查看器、视频/音频播放器、文本预览这些子窗口会跟着一起缩进任务栏。
现在它们都是独立窗口，最小化谁都不牵连谁。

## 🖌 打码 / 涂鸦的手感修好了

两个实测反馈：

- **在马赛克上涂鸦，笔迹要松手才出现**：打码层被排到了涂鸦层上面，
  正在画的那一笔整个被盖住，看起来像「点了没反应」。现在一拿起画笔，涂鸦立刻回到最上层。
- **纯色背景上看不出哪里涂过马赛克**：纯色块打码后还是纯色，痕迹没法辨认。
  现在打码区域会带一圈**很淡的双色描边**（深色底、浅色底都看得见），
  只用于屏幕预览，**导出的图片里没有这条边**，不影响成品。
- 涂抹过程中会跟着鼠标走一条细淡的提示线（带淡入），大图上也不会出现「笔都落下去了屏幕没动」的感觉。

## 🗂 侧栏：文件夹终于认得出来了

以前「文件夹」分组直接显示整条路径，侧栏窄被截成
`C:\Users\xxx\Videos\Capt…`，两个不同目录看起来一模一样，选哪个全靠猜。

现在**标题只放目录名**（`Captures`），下面一行小字是盘符 + 上级目录（`C:\…\Videos`），
鼠标悬停能看到完整路径。不同盘上同名的目录也能一眼分开。

另外把「分类」分组挪到了「文件夹」上面 —— 分类是你自己划的「分区」，比系统路径更常点，
不用再往下滚才找得到。


## 💾 换电脑 / 完整备份（.mmbak）

设置 → 备份与迁移 → 「📤 导出完整备份…」：把数据库 + **私密空间文件** + 日记 + 设置
打包成一个 `.mmbak` 文件（内置记录文件名，恢复时还原原名）。新电脑上点「📥 导入完整备份…」
选择这个包即可原样恢复，私密路径自动改写到新位置；导入前会自动把当前数据先备份一遍兜底。
老版本导出的 `.mmdb` 数据库文件也还能识别。

## 🎨 彩色文件类型图标

以前 txt / zip / mp3 这些显示的是 emoji（📄 🗜️ 🎵），而 emoji 能不能出彩色完全取决于
系统装了什么字体 —— 很多机器会回落成黑白字形，看着像「图标没加载出来」。

现在换成纯矢量绘制的彩色图标：圆角卡片 + 顶部高光 + 右上折角 + 白色类型标签。
按扩展名细分颜色和标签：

| 类型 | 颜色 | 标签 |
|---|---|---|
| PDF | 红 | PDF |
| Word / Excel / PPT | 蓝 / 绿 / 橙 | DOC / XLS / PPT |
| 文本 / Markdown | 灰蓝 | TXT / MD |
| 数据（json / yaml / sql） | 天蓝 | JSON / YML / SQL |
| 代码 | 紫 | C# / PY / JS / HTML… |
| 压缩包 | 黄 | ZIP / RAR / 7Z… |
| 音频 | 青 | MP3 / FLAC / WAV… |
| 电子书 / 字幕 | 棕 / 蓝 | EPUB / SRT |

标签按扩展名走，不再「所有音频都显示 MP3」；没有扩展名的文件显示 `FILE`，不瞎猜类型。
图标跟着缩略图大小滑块等比缩放。

## 🪶 极简模式（代替「简易版」）

设置 → 常规与外观 → 极简模式。开了只留基础入口：

- 保留：发现 / 全部媒体 / 收藏 / 文件夹 / 标签
- 隐藏：未分类 / 最近查看 / 最近添加 / 最近删除 / 日记 / 私密空间 / 整个「分类」分组 / 设置里的插件扩展

**只影响入口，一个文件都不会动**，随时可以关回来。

## 为什么没有「手机版」

这个软件是 C# + WPF，只能跑 Windows，做不了手机 App。要做「手机传照片到电脑」，
技术上可行的做法是电脑起一个局域网网页 + 二维码，手机同 WiFi 扫码上传（不需要写 App、不需要内网穿透）。
这一版先不做 —— 等 PC 端这几块稳定了再说。

## 升级说明

直接覆盖安装即可，数据库会自动补列和建表（`IsPrivate` / `OriginalPath` / `DiaryEntry` / `DiaryMedia`），
已有数据一条都不会动。

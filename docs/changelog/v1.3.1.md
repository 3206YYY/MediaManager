# V1.3.1 扩展格式支持（音频 / 文档 / 压缩包）

这一版把媒体管理器从「只管图片和视频」扩展到可以同时浏览**音频、文档、压缩包**，
并修掉了一批筛选、单实例、设置窗口和多显示器相关的体验问题。

> 当前状态：已发布。`dotnet build` **0 警告 0 错误**，`dotnet test` **179/179 通过**；
> 版本号 **1.3.1**，安装包 `MediaManager-Setup-1.3.1.exe`（101 MB）。

---

## 1. 新增：音频 / 文档 / 压缩包（只读浏览）

共支持 **80 个扩展名**：图片 13 / 视频 17 / 音频 15 / 文档 25 / 压缩包 10。

| 类型 | 扩展名 | 双击打开 |
|---|---|---|
| 图片 | `.jpg .jpeg .jpe .jfif .png .gif .webp .bmp .tif .tiff .ico .heic .avif` | 图片查看器（缩放、编辑） |
| 视频 | `.mp4 .mkv .avi .mov .wmv .webm .flv .m4v .ts .mpg .mpeg .3gp .mts .m2ts .ogv .rmvb .vob` | 内置 LibVLC 播放器 |
| 音频 | `.mp3 .wav .flac .m4a .aac .ogg .opus .wma .aif .aiff .amr .mka .ape .mid .midi` | 内置音频播放器（播放/暂停、进度、音量、0.5x~2x 倍速） |
| 文档 | `.txt .md .log .json .csv .xml .ini .yaml .yml .htm .html .srt .ass .ssa .toml` + 代码文件 `.py .js .css .cs .java .go .rs .sql .bat .ps1` | 只读文本预览（UTF-8 / UTF-16 / GBK 自动识别，超过 2MB 只读前 2MB） |
| 压缩包 | `.zip .rar .7z .tar .gz .bz2 .xz .tgz .tbz2 .txz` | 条目列表（名称 / 原始大小 / 压缩后大小）+「用系统程序打开」 |

- 三类在网格里用**固定图标**显示（音频统一一个图标），不额外生成缩略图，避免后台空转。
- 扫描只收录已知扩展名，其它文件一律跳过。
- 详情面板显示类型与大小；图片仍显示分辨率 / EXIF。

### 1.1 顶部「类型」多选筛选

- 顶部 **类型 ▾** 弹出面板：**全部 / 全不选** + `图片 / 视频 / 音频 / 文档 / 压缩包` 复选。
- 与左侧导航（库/文件夹/分类/标签）**交叉组合**：例如「风景」分类 + 只勾「音频」= 该分类下的音频。
- 勾选状态用主题化的**主色勾**显示，任意顺序勾选/取消都会正确刷新
  （修掉了「从上往下点正常、从下往上点失效」的事件时序问题）。
- 列表加载增加了**代次保护**：并发刷新时旧查询结果不会覆盖新结果。

### 1.2 发现页跟随类型筛选

- 发现页不再有单独的类型下拉，直接跟随顶部类型筛选。
- 每日批次现在会记录**生成时的类型键**（`DailyDiscovery.TypeFilter`，旧库自动迁移）：
  只有键一致才复用缓存，否则按当前类型重新生成。
- 修掉了「全选 → 从上往下取消 → 从下往上勾回 → 发现页只剩视频」的问题。

### 1.3 可选启用（设置 → 插件扩展）

- 设置页新增「扩展格式支持」开关（默认开启）。
- 关闭后不再**扫描**音频/文档/压缩包，已入库条目仍保留。
- **手动打开不受开关影响**：「👁 快速查看」、右键「用媒体管理器打开」、拖入文件，
  即使开关关闭也能正常预览 txt / mp3 / zip。

## 2. 文件夹选择器：Explorer 风格 + 系统图标

- 左侧目录树（驱动器/文件夹，展开时按需加载），右侧**缩略图网格**：
  - 图片显示真实缩略图（112px）；
  - 文件夹 / 其它文件显示 **Windows 系统文件图标**（`SHGetFileInfo` + `SHGetImageList`，
    优先 256px，退回 48px / 32px，按扩展名缓存）。
- 顶部快捷入口：用户目录 / 桌面 / 文档 / 下载；支持「上一级」，全程鼠标操作。
- 底部实时显示「此文件夹：N 个子文件夹，M 个文件」。
- 添加文件夹后若扫描结果为 0，会弹窗提示原因（例如关掉扩展格式后选了只有 zip 的文件夹）。

---

## 3. 单实例文件转发（右键打开修好了）

- 之前程序已在运行时，右键「用媒体管理器打开」只会把已有窗口叫到前台，**不会打开文件**。
- 现在第二个进程通过**命名管道**把文件路径转给已运行实例，由它打开对应查看器/播放器。
- 文本、图片、视频、音频、压缩包都走这条。

---

## 4. 设置窗口：非模态、可最小化

- 设置窗口从模态 `ShowDialog()` 改为独立 `Show()` 窗口，不再阻塞主界面。
- 最小化后再点「设置」会先还原（`WindowState = Normal`）再置前。
- 不再挂 `Owner`，主窗口与设置窗口各自最小化、互不影响。

- 「打开文件」改名「👁 快速查看」并补 ToolTip，和「＋ 添加文件夹」区分：

## 6. 技术说明

- `MediaType` 追加 `Audio = 2 / Text = 3 / Archive = 4`；`MediaItem.MediaType` 是 TEXT 列，
  旧数据零迁移。
- `MediaFilter` 支持 `MediaTypes` 多值筛选（`IN` 查询，兼容历史数字写法）。
- `DailyDiscovery` 新增 `TypeFilter` 列（`MigrateColumn` 自动补列）。
- 新增依赖：`SharpCompress`（rar/7z 读取，MIT）、`System.Text.Encoding.CodePages`（GBK）。
- 压缩包只读预览，不解压、不修改；大压缩包最多列出 5000 项。
- 文本预览超过 2MB 只读前 2MB，避免一次性读入巨大日志卡 UI。

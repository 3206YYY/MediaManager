# V1.3.2 产品减法：收藏夹并入分类

这一版只做一件事：**把「收藏夹」整个功能砍掉，能力与数据并进「分类」**。

起因是分类和收藏夹在定位上严重重合：都能装媒体、都能挂多个、都能在左侧导航里点开看。
两套并存的结果是 UI 多一块、右键菜单多一行、详情面板多一段，用户每次归类都要先做一道
「这个该放分类还是收藏夹」的选择题。这一版把这道题删掉。

> 当前状态：已实现并实机验证。`dotnet build` **0 警告 0 错误**，`dotnet test` **185/185 通过**
> （新增 6 条迁移测试）；版本号 **1.3.2**。

---

## 1. 数据迁移（升级老库时自动执行，一次性）

老用户的收藏夹数据**一条都不丢**。程序启动时 `DatabaseInitializer.Initialize()` 末尾会跑
`MigrateCollectionsIntoCategories`：

1. 读旧 `Collection` / `MediaCollection` 表；
2. 每个收藏夹 → `Category` 里一个**同名顶级分类**（`ParentId = NULL`），`SortOrder` 接在现有
   顶级分类之后，保持原来的相对顺序；
3. 已有同名顶级分类的**直接复用**，不建重复的（`Name` 比较不区分大小写）；
4. 媒体归属从 `MediaCollection` 搬到 `MediaCategory`，`INSERT OR IGNORE`，纯增量，
   不动用户已有的分类归属；
5. 旧 id → 新分类 id 记进 `CollectionMigrationMap`。

安全性设计：

| 关注点 | 做法 |
|---|---|
| 中途失败 | 全程一个事务，失败整批回滚，旧表一行不动 → 下次启动自动重试 |
| 重复启动 | `SchemaMigration` 台账记 `v1.3.2_CollectionToCategory`，之后每次启动只多一次 COUNT |
| 老表去留 | **保留**（不再有任何读写路径）。数据永远还在，确认没问题后可手工 `DROP TABLE` |
| 迁移失败不能开机 | 异常只记日志、不往上抛：用户暂时看不到旧收藏夹，但程序必须能打开 |
| 空收藏夹 | 也建成分类（用户建它是有意义的，马上要往里放东西） |
| 残留孤儿行 | 迁移时 `JOIN MediaItem` 过滤。SQLite 的 `OR IGNORE` **不忽略外键冲突**，老库若留下「指向已删媒体」的关联行，不过滤会让整批回滚、以后每次启动都失败 |
| 「最近删除」还原 | v1.3.2 之前的删除记录里还存着收藏夹 id，还原时经 `CollectionMigrationMap` 换算成分类 id，归类照样回来 |

**实机验证**（本机真实库 85 项媒体 / 1 个收藏夹「测试」/ 1 条归属）：
```
收藏夹已并入分类：1 个收藏夹 → 新建 1 个分类（0 个同名复用），迁移 1 条媒体归属
Category: [(8,'分类测试',SortOrder 1), (9,'测试',SortOrder 2)]
CollectionMigrationMap: [(1 → 9)]
旧表仍是原样：Collection[(1,'测试')] / MediaCollection[1 行]
```

## 2. UI 减法

- **左导航**：删掉「收藏夹」整个分组和「＋ 新建收藏夹」按钮。
- **右键菜单**：删掉「🗂 加入收藏夹」。
- **发现页**：推荐池第 4 项从「指定分类/收藏夹」改成「指定分类」，候选列顶级分类
  （走 `MediaCategory`，不再查 `MediaCollection`）。
- **查看器随机范围**：删掉「收藏夹」，剩「指定分类 / 标签」。
- **保留** 右上角 ⭐ 收藏（布尔标星）与 F 键——这是最基础的标记，不参与归类。
- **缩略图角标**只剩两个：⭐ 收藏（右上）、📁 分类（左上，`ToolTip` 列出分类名）。

## 3. 拖拽与详情面板

- 拖拽归类的落点统一到**分类**（`MediaCategory`）；拖到标签上仍是打标签。
- 详情面板把「已加入的分类」+「已加入的收藏夹」两段合并成一段 **所属分类**：
  - 每项右侧 ✕ **单独移出**；
  - 新增 **＋ 加入**：弹出可勾选清单，用 `MenuItem.StaysOpenOnClick` 让菜单勾完不收起，
    可以**连着勾多个分类**；再点一下已勾的项就是移出；
  - 一个分类都没有时显示「还没有归入任何分类」，避免空一块看着像坏了。
- **统一强反馈**：加入分类后底部弹轻提示 —— `✅ 已加入分类【xxx】`，
  批量则 `✅ 已将 N 项加入分类【xxx】`，移出是 `已从分类【xxx】移出`。
  1.8 秒自动消失，连续操作只留最后一条（不叠 10 条）。拖到标签同样弹 `✅ 已打上标签【xxx】`。
- **拖拽源是新写的**（之前只有「拖文件进窗口」，网格里往外拖根本不存在）：
  按住缩略图移动超过系统阈值才启动，数据同时带 `FileDrop`（可直接拖到桌面 / 资源管理器）
  和内部 `MediaIds`（拖到侧栏归类）。按在已选中项上拖整批，按在未选中项上只拖这一项；
  侧栏只在**命中具体分类/标签**时才允许放下，空白处是禁止光标、松手什么也不发生。
- 拖拽加入分类后，右侧「所属分类」会立刻刷新（原来是等下次重新选中才更新）。

## 4. 侧边栏一致性修复（顺手把真因找出来了）

表面问题是「分类/标签的折叠和悬停看着不一样」，实际有三层：

1. **悬停完全没反应**：全局隐式 `TextBlock` 样式把 `Foreground` 写死成 `TextBrush`，
   而 `SidebarItemStyle` 的 hover 是改宿主 `ListBoxItem.Foreground` —— 子元素的显式样式
   优先级更高，宿主设的颜色根本传不下去。修法：新增 `SidebarText` 样式，
   把文字颜色绑定到最近宿主 (`AncestorType=Control`) 的 `Foreground`，用 local value 顶回去。
   现在悬停整行文字一起变主色。
2. **分区标题不统一**：「库」「文件夹」是不可折叠的粗体 `TextBlock`，「标签」「分类」是可折叠
   `ToggleButton`。现在四个分区**同一套**：`SidebarSectionHeader` 样式 + 同款 `▼/▶` 箭头 +
   同款计数（`Opacity 0.65` 代替另配灰色），`OnToggleSection` 增加 `Nav` / `Folder` 两个分支。
3. **对齐细节**：箭头统一 `SidebarChevron`（10px、垂直居中、不用空格排版），
   计数统一 `FontSize 11` + 4px 左间距。

## 5. 顺手修掉的两个老问题

- **搜索索引其实一直是坏的**：`MediaFts` 是 external content 表（`content='MediaItem'`），
  却多了 `Tags` / `Categories` 两个虚拟列。fts5 的 `'rebuild'` 和直接 `UPDATE` 都会去
  content 表读这两列，于是稳定报 `no such column: T.Tags` —— 原来的 `RebuildFtsAsync`
  两句话都跑不通，而且**没有任何地方调用它**，标签/分类名从来没进过索引。
  现在改成 `delete-all` + `INSERT ... SELECT`（连标签/分类名一起灌），迁移尾部也会重建一次索引，
  所以按新分类名能直接搜到那批媒体。
- **「所属分类」按钮布局**：`DockPanel` 默认 `LastChildFill=True`，最后一个子元素会被拉满，
  按钮占满整行还溢出裁切。改为 `LastChildFill="False"` + 两侧 `Dock`。

## 6. 同批次的其他改动

这一版除了收藏夹减法，工作区里还带着几处之前没发出去的修复，一并进这个包：

| 位置 | 改动 |
|---|---|
| 缩略图 | 缓存文件名从 `{Id}_0.jpg` 改成 `{Id}_{大小}_{修改时间}.jpg`。原来只带 Id（`QuickHash` 其实从没写入过），同一个 Id 只要路径不变就永远复用旧图 → 编辑器「原地覆盖副本」后列表仍显示旧画面、删掉副本再重建还会撞上上次的缓存。现在内容一变就是新文件名。 |
| 刷新按钮 | 手动刷新时连解码后的内存 LRU 一起丢掉，不再只重读数据库。 |
| 文件夹选择 | 「添加文件夹」改回系统原生选择器（`IFileOpenDialog` + `FOS_PICKFOLDERS`）：左侧导航、网络位置、新建文件夹与资源管理器完全一致。v1.3.1 的自绘选择器代码保留在 `Views/Dialogs/FolderPickerWindow.*`，只是不再被调用。 |
| 编辑器·文字 | 「斜放角度」和「缩放比例」支持直接输入数字：角度 0–360（360 = 0），缩放 20%–300%（100% = 48px）。回车或失焦生效，与滑块双向同步。 |
| 视频播放器 | 不再挂主窗口 `Owner`：主窗口一最小化，视频窗口会被系统一起收走，只剩黑屏。现在做成独立顶层窗口。 |

## 升级须知

- 覆盖安装即可，数据在 `%LocalAppData%\MediaManager`，升级只换程序。
- 升级后第一次启动会看到旧收藏夹变成同名分类；**旧表还在**，确认无误后可自行删除。
- 收藏夹的**颜色字段**（`Collection.Color`）没有对应概念，迁移时丢弃（分类本来就没有颜色）。

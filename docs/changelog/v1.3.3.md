# V1.3.3 稳定性与手感：把手上这些账清掉

这一版以「已有功能不好用 / 有隐患」的修复为主，覆盖交互手感、扫描入库、数据安全三条线；
编辑器另外加了两处交互改进：点分类即进入工具、整笔删除的橡皮擦。

> 当前状态：`dotnet build` **0 警告 0 错误**，`dotnet test` **204/204 通过**；版本号 **1.3.3**。
> 人工烟测清单见文末。

---

## 1. 双击手势全部移除

- **视频播放器**：双击不再全屏。原来「单点快一点」会被系统识别成双击，直接跳全屏并暂停，很突然。
  现在改为**两次点击合并**：150 ms 内的连点只算一次播放/暂停切换，不会再触发全屏。
  全屏统一走 `F` / `F11` / `Esc` / 控制栏按钮。
- **图片查看器**：双击不再「适应窗口」。原来快速两次点击会让画面突然缩小，现在删掉该手势，
  改用 `Ctrl+0`（与工具栏按钮一致），`Ctrl+1` 回到 1:1。

## 2. 查看器手感

- **拖动死区**：适应窗口状态下按住左键轻微抖动不再把画面拖歪，超过系统拖动阈值才进入平移。
- **平移范围夹紧**：放大后拖动不会把图片拖出画布，边缘始终贴边。
- **切工具不复位视口**：放大到 1:1 再点「打码」，缩放和平移保持不动（原来会跳回适应窗口）。
- **缩放百分比改成真实比例**：显示的百分比与实际像素比例一致，不再有四舍五入的偏差。

## 3. 编辑器

- **马赛克与画笔可叠放**：两个工具不再互相覆盖。叠放顺序跟随「最近一次用的是哪个工具」——
  先画笔后马赛克，马赛克盖住涂鸦；再落一笔，涂鸦回到马赛克之上。
  预览、保存副本、撤销/重做三处使用同一顺序（`EditorDocument.PrivacyAboveInk` 进入快照）。
  注意：工具栏仍是互斥切换，同一时间只激活一种工具，这一版改的是**渲染层级**。
- **打码涂抹性能**：涂抹时不再每帧重建整层，改为缓存几何与取样底图。
  新旧实现做过逐像素回归对照，渲染结果**平均像素差 0.00**，画面完全一致。
- **点分类即进入工具**：点「标注」直接可以画、点「打码」直接可以涂抹，不用再点面板里的「✏ 涂鸦 / ▦ 涂抹打码」开关；
  切到基础 / 调色 / 文字 / 水印时自动退出绘制工具——原来切走后涂鸦层仍盖在最上面，文字根本点不中。
- **新增橡皮擦**：标注面板和打码面板各有一个「🧽 橡皮擦」，拖过的地方**整笔删除**
  （涂鸦、涂抹打码、矩形马赛克都算，文字与形状仍用点选删除）。
  一次拖动 = 一个撤销步骤，空拖不写撤销栈；`Esc` 退出工具。

## 4. 扫描与入库

- **系统垃圾文件不再入库**：`desktop.ini` / `Thumbs.db` 等（按文件名 + 隐藏/系统属性判定）在扫描时直接跳过；
  `.ini` 也从文档白名单里移除。历史版本误收录的记录由一次性迁移 `v1.3.3_JunkMediaPurge` 清理——
  **只删数据库记录，磁盘文件一个不动**。
- **图片宽高回填**：扫描时读取文件头写入 `Width/Height`（原来这一列从来没写过，界面全部显示「未知」）；
  启动后后台补历史数据。补录过程中只要一整批（400 条）一条都读不到（移动硬盘没插 / 文件损坏）就立即收工，
  不会反复重查同一批行空转。
- **批量事务入库**：一批 500 个文件从「逐条开连接 + 逐条 SELECT + 逐条写」（1000+ 次往返）
  降到 2 次查询 + 1 次提交。
- **进度计数修正**：「新增 / 更新」改为逐文件累加。原来写在「攒够一批」的分支里，
  等于每 500 个文件只按最后一个文件记一次，尾部不足一批的完全不计。
- **根目录恢复改真异步**：盘符变化后按卷序列号恢复路径时直接 `await` 写库，不再用
  `Task.Run(...).GetResult()` 同步阻塞调用线程。

## 5. 数据安全

- **数据库导出 / 恢复的连接不再池化**：两处都改用 `SqliteConnectionStringBuilder` + `Pooling=false`，
  并去掉已废弃的 `Cache=Shared`。原来池化连接在方法返回后仍占着文件句柄——导出的库在 U 盘里拔不掉；
  更严重的是紧接着的 `journal_mode=DELETE` 抢不到锁会静默失败，用户只拷走单个 `.db` 时会丢掉还在 `-wal` 里的最新数据。
- **消除潜在死锁**：`MediaRepository` 的 85 处 `await` 全部补上 `ConfigureAwait(false)`；
  剩余 3 处确实需要同步等待的调用（主窗口关闭时读写 CloseBehavior、备份服务属性）改为
  `Task.Run(...)` 后等待，不再依赖同步上下文。

## 6. 搜索与数据库并发

- **子串搜索改走 trigram 索引**：新增 `MediaFtsTrigram`（FTS5 `tokenize='trigram'`，external content 挂 `MediaItem`），
  文件名/路径的子串查询（≥3 字）从整表 `instr(lower(...))` 扫描改为索引匹配。
  1~2 字的短查询仍退回 `instr`（本来就快）；标签/分类名继续走原来的 `MediaFts`，两者取并集。
  一次性的 `BuildTrigramFts` 迁移把已有媒体灌进索引，失败或引擎不支持 trigram（SQLite < 3.34）时
  自动退回旧的 `instr` 路径，功能不受影响。
  搜索加了 **300 ms 防抖 + 取消上一次查询**，输入过程中不会堆积重复查询。
- **SQLite 连接改私有缓存**：`SqliteConnectionFactory` 的 `Cache` 从 `Shared` 改为 `Private`。
  SQLite 官方已不推荐共享缓存——多个连接会在表级互相加锁，容易出现 `SQLITE_LOCKED`；
  本项目本来就是「每次操作新开连接 + WAL」，私有缓存是标准组合。
- **搜索结果的批量绑定**：`RangeObservableCollection.AddRange` 一次 `Reset`，不再逐项触发
  `CollectionChanged`（列表项多时能省掉成百上千次 UI 通知）。

## 手工验证清单

1. 播放器里快速连点画面 → 只切换一次播放/暂停，不进入全屏。
2. 查看器适应窗口下按住左键乱晃 → 画面不动；放大后能拖，且拖不出边界。
3. 放大到 1:1（`Ctrl+1`）→ 点「打码」→ 缩放保持不变。
4. 编辑器：先画笔后马赛克 → 马赛克盖住涂鸦；再画一笔 → 涂鸦回到最上；`Ctrl+Z`/`Ctrl+Y` 顺序可还原。
5. 扫描一个含 `desktop.ini` 的目录 → 图库里不再出现文档图标。
6. 设置里「导出数据库」到 U 盘 → 只保留单个 `.db`，无 `-wal`/`-shm` 残留，且能直接拔盘。
7. 编辑器里点「标注」→ 不必再点开关就能画；点「打码」→ 直接能涂抹；切到「文字」→ 涂鸦层让开，能点中文字。
8. 橡皮擦拖过一段涂鸦 / 一块打码 → 整笔消失，`Ctrl+Z` 一步还原。
9. 覆盖安装后从开始菜单启动 → 快捷方式指向 `%LOCALAPPDATA%\Programs\MediaManager`，不再指向临时目录。

## 已知限制

- trigram 索引按「3 个字符」切词：查询里若混有 1~2 字的词（如「a bcd」），该词不会命中 trigram，
  只能靠 `MediaFts`（标签/分类）或短查询兜底路径补上。
- trigram 索引会让每次写入多维护一张虚拟表，库文件也会相应变大（约为文件名/路径文本的 3 倍），
  换来的是子串搜索从全表扫变成索引查。
- 自动更新（NetSparkleUpdater）、AI 打标 / 人脸 / 去重仍未做。

## 升级须知

- 覆盖安装即可，数据在 `%LocalAppData%\MediaManager`，升级只换程序。
- 安装目录从本版起固定为 `%LOCALAPPDATA%\Programs\MediaManager`：以前若因测试安装把位置记到别处，
  这一版会纠正回来，开始菜单 / 桌面快捷方式随之更新，不会再「点开还是旧版本」。
- 升级后第一次启动会自动清理历史上误入库的 `desktop.ini` / `Thumbs.db` 记录；**磁盘上的原文件不会被删除**。
- 老库首次启动会多跑一次尺寸回填，图片较多时列表里的「未知」尺寸会在后台逐步补齐。

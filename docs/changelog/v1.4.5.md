# v1.4.5 — 文件夹不再「明明有货却显示 0 项」，批量删除终于看得见

## 这一版做了什么

这一版有两个来源：一是**真实用户报的错**（点开文件夹说里面没文件），二是**小白用户卡住的地方**（不知道怎么多选、怎么删）。

1. **嵌套文件夹的「0 项」bug 修掉了**。
   如果你先添加了 `C:\照片`，后来又单独添加了 `C:\照片\2024`，以前会出现两条平行的根目录：
   点子目录那条显示 0 项、点进去说「这个文件夹没有文件」，而文件其实都在父目录那条里。
   现在添加时会识别出「它已经在库里的父目录下面」，不再建重复根目录；已经中招的库**启动时自动自愈**：
   把子目录下的记录并回父目录，再删掉那条重复的根目录。实测把一个重复的 `C:\测试\实拍`
   并回主根目录，**86 条媒体一条没少**，数据库完整性检查通过。

2. **扫描进度的数字不再骗人**。以前扫描小文件夹时，进度只会显示「0 个文件」，扫完才跳；
   而且「新增 N 个」是按「这个根目录已知路径」估的，写库却按绝对路径去重 —— 报了「新增 3 个」，
   实际一条没进库。现在新增 / 更新分别计数，扫描一结束就把真实条数报出来。

3. **顶层文件夹默认展开**。以前根目录前面的三角形是收着的，子文件夹躲在后面，
   新手以为「我明明加了文件夹怎么只有一项」。现在默认展开第一层，一眼看到全部子目录。

4. **顶部新增「🗑 批量删除」按钮**（可以不用记 Delete 键了）。它会随状态变形：
   - 什么都没选：普通样式，**点了也能用**（以前是灰的，点了没反应，用户以为功能坏了）；
   - 已经选了：高亮显示「删除选中的 N 项」，点它就是原来的确认框 → 回收站 → 5 秒撤销；
   - 正在删除模式：变成「退出删除模式」。

5. **删除模式默认「先勾选，再统一删除」**（手机相册式）。点开按钮后，单击只给文件打勾，
   挑完点下面「删除选中的 N 项」并确认 —— 不会一进模式就误删。
   取消那个勾才切换成「点谁删谁」，连点连删。两种都在，随时切换，按 Esc 退出。
   旧的多选方式（Ctrl / Shift 点击、拖框、Ctrl+A、Delete 键、右键菜单）**一个都没动**。

6. **设置里新增「❓ 帮助与快捷键」页**（状态栏右下角也能一键进）。三步上手指引、
   「怎么一次选中多张、怎么删除」的图解式说明、功能速览，加上按全局热键 / 主界面 /
   图片查看器 / 图片编辑器 / 视频播放器分组的完整快捷键表。这一页是按需加载的，
   不影响启动速度。

## 升级说明

从 v1.4.x 直接覆盖安装即可，数据不动。第一次启动会做一次根目录去重自愈（只动库索引，
不移动、不删除任何磁盘文件），耗时取决于重复目录下的条目数量，一般不到一秒。

如果你之前手动删过重复的根目录、或者把同一个文件夹加了两次，这一版之后都不需要再管它。

# 更新说明 · v1.4.10

这一版把图片编辑器改成「点哪个图标，画布上立刻就能用」：点「裁剪」直接出裁剪框（默认就是整张图），点「文字」直接出可输入的文本框，打码时鼠标上带一个跟着笔刷大小缩放的圆圈；顺带修掉了几个别扭的地方——裁剪切走后再也不会把缩放和位置重置、切工具不再留下「输入文字」四个字、敲完字按一次撤销就能干净退回、按住 `\` 看原图时画笔画圈和裁剪框都会收起。主界面还多了「网格 / 列表」两种看图方式，列表里每行直接给出大小、修改时间和视频时长，切换和重启后都会记住你的选择。

## 编辑器：点一下就用，不用再进面板找按钮

- 点「裁剪」画布上立刻出现 8 个手柄的裁剪框，默认整张图；点「取消」或切到别的分类，缩放和画面位置恢复到进入前。
- 点「文字」立刻出现可输入的文本框；一个字没打就切走，不会在成品里留下「输入文字」，撤销栈也不会多一条。
- 打码时画笔圆圈跟着鼠标走，直径随画笔大小和缩放实时变化；切到「拖一个矩形」或按住 `\` 看原图时自动隐藏。
- 打码面板补了一句说明：边缘那圈淡描边只是为了让你在纯色背景上也能看清涂过哪里，保存和导出的成品里不会有。
- 敲完一行字按一次撤销，直接回到「没加过字」，撤销按钮同时变灰，不用再按第二次。
- 按住 `\` 对比原图时，马赛克、文字、标注、水印、画笔圈、裁剪框等辅助线全部收起，松开后自然恢复。

## 主界面：网格 / 列表两种看法

- 顶栏新增「网格视图 / 列表视图」切换，旁边就是熟悉的排序和筛选。
- 列表里每行是 48px 缩略图加文件名，右侧给出大小、修改时间和视频时长；同名文件悬停可看完整路径。
- 切换视图时已选中的文件不会丢，重启后仍停在上次选的视图。
- 列表模式照样支持 Ctrl 多选、从空白处框选和底部批量删除；「缩略图大小」只在网格模式出现，不会在列表里露出来。
- 发现页的「换一批」按钮不再把快捷键写进按钮文字，快捷键提示改到悬停说明里。

## 测试与守卫

- 新增 `verify_editor_tool_modes.py`（54 项）与 `verify_view_switch.py`（44 项）两个实机脚本；全量回归 31 个脚本全部通过。
- 像素比对小工具从被忽略的 `artifacts/` 挪进 `build/overlaycheck/` 并入库，守卫每轮真跑：导出图与「不带描边」渲染的差异为 0.003（≈0），预览带描边为 0.705，成品确实没有那圈淡描边。
- `verify_code_health` / `verify_design_tokens` / `verify_toolbar_anchors` 同步更新，设计令牌欠账只减不增。

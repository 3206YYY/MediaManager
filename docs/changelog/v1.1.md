# 媒体管理器 V1.1 更新说明（可直接转发）

V1.1 主要解决两件事：手滑删错、弹窗刺眼。

1. **删除可撤销**：删掉文件后，屏幕下方会弹出「已删除 X 个项目」，5 秒内点「撤销」就能原样恢复。左侧新增「最近删除」，随时看看自己删过什么，再决定还原还是彻底删除。
2. **缓存看得见**：设置里能看到缩略图缓存占了多少空间，一键清理，原图和视频不受影响；数据、缓存、备份目录旁都加了「📂 打开目录」，找文件不用再翻路径。
3. **弹窗不再刺眼**：所有系统弹窗换成了跟随主题的样式，深色模式下不会再闪出白底窗口；关窗口时也能清楚选择「最小化到托盘 / 直接退出 / 取消」，还可以记住这次选择。

覆盖安装即可，收藏、分类、备注都会保留。

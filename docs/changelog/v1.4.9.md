# 更新说明 · v1.4.9

这一版把主界面从头到脚收干净了：顶栏不再一排按钮挤成两条，只留「＋ 添加文件夹」，去重、快速查看、缩略图大小收进右边的「⋯」里；内容区抬头合并成一条——「标题 · 结果数」加面包屑，窗口拉到 1020 宽、双栏都展开时也不会再把标题挤没。列表为空时中央不再是干巴巴一句「共 0 项」，而是分「加载中 / 空 / 出错 / 离线 / 筛选无结果」给出标题、说明和刷新按钮，说明文字和状态栏共用同一句诊断；右侧详情栏也分成没选、单选、多选三种状态，多选时直接告诉你选中了几项、前三个文件叫什么，批量操作仍然只在底部那一条。底层把字号和间距收进了统一令牌（23 档字号、7 档单值间距），所有窗口的字号硬编码已经归零，视觉效果和以前一致，后续改版不用再逐个窗口翻数字。

## 顶栏和内容区抬头，各收成一条

- 顶栏主操作只留「＋ 添加文件夹」；「查找重复文件」「快速查看」「缩略图大小」收进右侧「⋯」弹层，鼠标移开自动收起。
- 内容区抬头合并成一条：左边是「标题 · 结果数」和面包屑，右边是排序和筛选，不再上下两行。
- 面包屑过长会省略，悬停可看完整路径。
- 修掉一个窄窗口下的挤压问题：1020 最小宽度 + 左右栏都展开 + 发现页切到「指定分类」时，标题会被压成 0 宽；现在给标题列留了最小宽度，两个下拉也收窄，标题和计数都能完整显示。

## 列表空着的时候，终于说清楚为什么

- 中央空状态按「加载中 / 空 / 出错 / 离线 / 筛选无结果」分别给标题、说明和「刷新」按钮。
- 说明文字直接复用状态栏那句诊断，不会出现两处说法不一致。
- 读库失败不再只留下一个空列表：会明确写「读取媒体库失败」并给出排查建议。
- 已有内容时刷新不闪加载遮罩；删除或移出后列表变空，文案会改成「这个视图里已经没有文件了」，不沿用上一次视图的诊断。

## 详情栏分三态，多选不再装成单选

- 没选中：显示「未选择文件」和怎么多选的提示。
- 单选：原来那套名字、日期、EXIF、标签。
- 多选：显示「已选中 N 项」和前三个文件名，批量操作仍然只放在底部选择条，不会在右侧再复制一份删除入口。

## 字号和间距进了统一令牌

- 所有窗口的字号硬编码清零，统一走 23 档字号令牌；间距先落地 7 档单值刻度，不对称留白留在台账里逐步迁。
- 新增三张「只许减不许增」的欠账台账（颜色 / 字号 / 间距），迁一处降一处，防止回潮。
- 这一项不改视觉：迁移时逐位对齐原值，肉眼无变化。

## 测试与守卫

- 单元测试 467 项全绿（Core/Infra 389 + App 78）。
- 新增 `verify_empty_state.py` 等 5 个实机脚本；设计令牌守卫扩到 22 项。

下载 `MediaManager-Setup-1.4.9.exe` 覆盖安装即可，设置和媒体库都在原处，不受影响。

# 媒体管理器 V1.2.1 更新说明

> 这次没有加新功能，只干了一件事：**把这个软件变快、变小。**

## 体积：从 182MB 砍到 99MB

装完占的地方差不多小了一半。原因很直接——之前打包时把两样完全用不上的东西一起塞进去了：

- 一个 `ffprobe.exe`，105MB，代码里一行都没调用过；
- 视频组件里给 32 位系统和 ARM 准备的另外两套运行库（196MB），你的电脑根本用不到。

顺手还把几个没用的依赖包删了。功能一个没少，视频照样能放。

## 启动：点开就有窗口

以前双击图标，要盯着桌面发呆 2 秒多窗口才出来——因为程序在**开窗之前**就把数据库、配置、列表全读完了才肯显示。

现在顺序反过来了：**先把窗口画出来（约 1.2 秒），再去后台搬数据**。窗口出来后大约 0.1 秒，列表就填好了。中间你甚至可以直接点菜单，不会有"未响应"的白屏。

## 滚动：不再一卡一卡

之前缩略图是在**界面线程**上同步读盘解码的，你滚得越快它越卡。

现在解码全丢到后台线程去做，滚到哪就加载哪，加载完自动补上；快速划过的地方不会白干活。内存里还加了一层带**硬上限（200MB）**的缓存——以前是个无上限的字典，翻几千张图能一直涨。

设置页的「缓存」现在会同时显示磁盘缓存和内存缓存各占多少。

## 其他

- 弹窗、提示条去掉了投影效果（低端显卡/核显上这个特别费），看起来更干净，也不掉帧了。
- 详情面板的 EXIF 改成**点中哪张才读哪张**，按住方向键快速翻图不会再排队卡顿。
- 顺带修了一批"后台任务异常被吞掉"的隐患，出问题会记日志，不再假死。

---

如果你是按之前的版本升级的，安装包会覆盖程序文件，**图库数据、收藏、标签、备注都不受影响**。
装完第一次打开可能会慢一点（系统在扫新文件），之后就快了。

# v1.4.1 — 私密空间可选密码、日记年视图、深色模式修正

这一版没有大改版，全是「用起来顺手一点」和「颜色终于对了」。

## 🔑 私密空间：密码可选，你自己决定

私密空间窗口顶栏多了一个按钮，文字直接告诉你当前状态：

- 没设过 → 显示「🔑 设置密码」，点一下进设置窗
- 设过了 → 显示「🔑 密码已开启」，点一下弹出「✏ 修改密码… / 🔓 取消密码…」

**代码一次都不会主动弹窗催你设密码。** 不想设就永远不点它，私密空间一直是点一下就进。
设了的后果很简单：关掉窗口后再进，先问一次密码；输错了原地提示重试，不关窗、不清输入。

几条实话写在这里，也写在设置窗里：

- 密码只在本机校验，存的是 PBKDF2-SHA256 派生值（15 万次迭代 + 随机盐），**不存明文**
- 保险箱**不加密文件**，它只是把文件挪进数据目录下的 `Vault` 文件夹并设成隐藏。
  所以密码忘了**不会丢数据** —— 打开「显示隐藏文件」就能把文件直接拷出来
- 密码防的是「知道这台电脑的人随手点开」，不防取证。要防取证请用磁盘加密

取消密码需要先验证原密码，验过之后文件仍然藏着，只是不再问。

## 📅 日记：新增年视图

日记窗口顶栏加了「📅 年视图 / 📅 月视图」切换。年视图里是 12 个方块：

- 写过回忆的月份主色高亮，直接显示「N 篇」；空的月份压成次要灰、显示「—」
- 点任意月份 → 跳回那个月的日历，160ms 淡入过渡
- 年视图下翻页箭头改成**翻年**，「今天」改成**回今年**

年度标题会顺手告诉你这一年写了多少篇（例：`2026 年 · 共 21 篇`）。

## 🌙 深色模式：日期选择器终于不是白板了

之前日记里点日期框弹出的日历是一片白底 + 浅灰字，什么都看不见。原因是 WPF 自带的
`CalendarItem` 模板把背景硬编码成白色，只改颜色根本改不动。这次整套重写了
`Calendar` / `CalendarItem` / `CalendarDayButton` / `CalendarButton` / `DatePicker` /
`DatePickerTextBox` 六个模板：

- 深色下日历底是深灰，日期数字白色，选中的日期主色高亮 + 白字，今天描一圈主色
- 不是本月的日期压暗，悬停提亮
- 浅色主题照旧，两套主题共用同一份模板，只换画刷

同时修了私密空间顶栏「⭐ 收藏」按钮：它之前没套样式，退回了系统默认白底模板，
深色下是白底白字糊成一团。现在和主界面「📝 已编辑」用同一套胶囊开关，
并且补上了**禁用状态**的样式（背景变浅一档、文字退到次要灰、整体 75% 透明、光标变箭头）。

## 📂 音频 / 文档 / 压缩包改为系统默认程序打开

以前双击 mp3 / txt / zip 会弹一个功能很有限的半成品内置窗口 —— 音频只能播不能管，
文本只能读不能编辑，压缩包只能看条目不能解压。这一版直接交给系统：

- 双击 → 调用系统默认关联程序（你的 Foobar / PotPlayer / VS Code / WinRAR）
- 没有关联程序时给一句人话提示，不会静默失败
- 新增右键「📂 用系统默认程序打开」和快捷键 `Ctrl + O`，所有媒体类型都有
  （包括图片和视频 —— 想拿 Photoshop 精修时很方便）

**图片和视频仍然走内置查看器**，一个都不外放：原地随机跳转、快捷键切图、调起编辑器、
跳去那天的日记，这些都得自己画窗口才做得出来；深色模式融合、拔盘不崩也是。

## 🔧 顺手修的

- 右键菜单现在作用于**你真正右键的那一项**。以前右键一个未选中的缩略图，
  菜单里点「删除」删的却是上次选中的那批 —— 这个隐患修掉了
- 右键集成卸载残留：`ShellIntegration` 这个 DWORD 值会让注册表键永远非空，
  Inno Setup 的「删空键」判定见不到空，导致 `Software\MediaManager` 留给下一次安装。
  现在卸载时显式删值再删键
- 私密空间的密码框在深色模式下是白底（`PasswordBox` 和 `TextBox` 是两个独立控件，
  不继承样式，之前谁都没写）

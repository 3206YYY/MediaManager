# 更新说明 · v1.4.8

这一版主要把「删除」这条链路从头到尾捋直了：设置里选「永久删除」，以前文件照样进回收站；选「每次询问」，以前从来不问——现在所有删除入口（批量删、点谁删谁、单张删、私密空间、去重窗口）都读同一个设置，连确认框里的每句承诺都按当前窗口真实有的补救方式说。同时新加了「永久删除前先确认」开关（默认开着），嫌逐张确认烦可以关掉，关掉后界面文案也会跟着改口，不会再说「每次都会确认」。设置页的「取消」现在也是真的取消：那些点了就生效的开关会退回原样，不会再出现「勾了、后悔了点取消，注册表已经被改」。剩下的都是零碎修补——缩略图上两个画上去的假按钮没了、取消选中后详情栏不再留着上一张的信息、Ctrl+A 只选一屏现在会明说、收藏数会跟着变、发现页和最近查看也会守筛选条件了。

## 删除方式这个设置，终于是真的了

这是一个「设置写了、代码没读」的老问题，而且是最危险的那种：

- 选「永久删除」，四处删除入口全写死走回收站，文件根本没被永久删掉——你以为删干净了，其实还在硬盘上。
- 选「每次询问」，执行端把它当成「进回收站」，从来不问你，属于半空开关。
- 私密空间的确认框还写着「可以在设置里改为永久删除」，可那儿根本没有这个选项。

现在删除的行为、文案、要不要先问一句，全部收在一个地方（`DeletePolicy` + `DeletePrompt`），界面只负责把字贴上去：

- 批量删除、删除模式点谁删谁、单张删除、私密空间、去重窗口，五条链路用的是同一个设置。
- 永久删除不留「最近删除」快照、不弹撤销条——文件已经从磁盘上没了，再承诺「5 秒内可撤销」就是骗人。
- 私密空间和去重窗口不再照抄主窗口那句「底部 5 秒内可撤销」：前者只有系统回收站，后者是「最近删除」里的快照，各说各的真话。
- 「每次询问」现在是真正的三选一：移入回收站 / 永久删除 / 取消，当场选。

## 永久删除前要不要确认，你说了算

以前只要是永久删除，每张图都拦一下，批量清截图时很烦。设置 → 常规与外观 → 删除行为 下面多了一项：

- **默认开着**，行为和以前一样（每次永久删除都先问）。
- 关掉之后，永久删除点了就直接执行：不进回收站、没有撤销、也不再问。
- 这一项只在删除行为选「永久删除」时可勾；选「回收站」或「每次询问」时它是灰的——那两档本来就每次都会问，留着可勾只会让人误以为关掉能少一道闸。
- 关掉后，主界面删除模式的红条、批量删除按钮的提示、底部删除按钮的提示都会同步改成「不再确认，点了就没了」，不会留一句「每次都会确认」的假话。

## 点「取消」就是真的取消

设置页里有两个开关是**点击即写**的（右键菜单集成要写注册表、扩展格式要写库 + 改静态开关），以前点「取消」只是把窗口关掉，改动早就生效了。

- 现在点「取消」、或者直接点标题栏 ×，都会把这一类开关退回打开设置时的样子。
- 回滚只做一次：以前「取消」按钮回滚一次、`Close()` 又触发一次，扩展格式那条等于连写两遍库。
- 写库改走线程池 + 有界等待，不再在 UI 线程上死等（原来是发射后不管，写失败也没人知道）。

## 缩略图上那两个按不动的按钮不见了

鼠标移到缩略图上会浮出一条快捷条，上面有「🏷 标签」「📁 文件夹」「⭐ 收藏」三个图标。前两个是画上去的**假按钮**——点下去什么都不会发生，还正好压在图片右下角最想看的位置；那层渐变遮罩本身也在吃点击，双击图片经常没反应。

- 只留真正能点的「⭐ 收藏」。
- 遮罩不再拦截点击，双击进查看器、右键菜单恢复。
- 打码、编辑那类辅助线只出现在预览里，导出默认关掉（这条以前就定了，顺手又核了一遍）。

## 几处「看着像坏了」的小毛病

- **取消选中后详情栏还留着上一张的信息**：点空白处清空选择后，右侧名字、日期、EXIF、标签全挂在那儿，像是选着一张不存在的图。现在会一起清空。
- **Ctrl+A 只选当前这一屏**：为了保证十万张时不卡，全选只作用于已经加载出来的部分。以前状态栏什么都不说，看着像「全选了却只删了一页」。现在会明写「已选中 N 项（只是已加载的部分；共 M 项，滚动加载更多后可继续选）」。
- **收藏数不刷新**：点星标收藏，左上角的收藏计数要重启才变。现在立刻跟着变。
- **发现页 / 最近查看不守筛选**：在「发现」页或「最近查看」里选中文件类型、加关键词筛选，列表纹丝不动——因为这两条路径在拼筛选条件之前就 return 了。现在筛选口径和主列表一致。
- **刷新会把诊断信息盖掉**：状态栏本来写着「未选择任何类型」，一刷新就被「共 0 项」顶掉，看着像库里空了。现在两种诊断都会被保留。

## 两侧栏可以收起来了

想把图看大一点，不用再拖窗口：左侧导航栏和右侧详情栏的边缘各挂了一个小把手，点一下就收起，再点一下展开。

- 收起后中间那栏吃掉全部宽度，一行能多放一列缩略图。
- 收起状态会被记住，下次打开还是收着的。
- 展开态的把手长在侧栏标题行里，不压在照片上；收起态的把手贴着边缘，带描边和阴影，指过去就亮。

## 选中不再「点了看不出」

之前选中状态用的是系统默认高亮，颜色只从缩略图四周那 4 像素的缝里透出来，深色主题下几乎和没选一样。

- 选中格子加一圈 3px 描边 + 右上角圆形勾选标记，浅色深色都清楚。
- 删除模式改用琥珀色（`#F58C2E`），**刻意不复用平时的蓝色**：删除是不可逆动作，颜色必须一眼分得开。
- 勾选标记往左让了 28px，不会和收藏星标、分类角标打架。

## 点一张却选中一串

根因不是选择算法，是框选状态没收干净：在空白处开始框选后，如果鼠标在窗口外松开、或者窗口被最小化，程序收不到「松手」这件事，就一直以为还在框选；下一次单击任何一张，都会拿「上次的起点 → 这次的位置」画一个大框，把中间的全圈进来。

- 任何一次按下鼠标前，先把上一轮的框选状态收干净。
- 窗口最小化、失焦、捕获被别人抢走时也会立刻收尾。
- 框选途中松掉 Ctrl 不会再把已经选好的反选掉。

## 删掉一张，手上的勾选不会一起没

删除模式里勾了 5 张，顺手点删其中一张，剩下 4 张的勾选会全被清空——因为删文件会触发一次整表重载，列表整体重建，选择自然没了。

- 删除前先把「还要保住哪些」记成 id 名单，重载完成后按 id 认回来。
- 点空白处也不会再清空已勾选项：用户是「勾一堆、再统一删」，点偏一下不该前功尽弃。删除模式下的框选也改成只加不减。

## 详情面板不再是一屏空行

EXIF 面板之前把「键名」和「值」存成了同一个字符串，界面上只剩「1080:」「1920:」这种没头没尾的行。

- 键名和值分开显示，例如 `Image Width：1080`。
- 顺带过滤掉 AI 出图工具塞进 PNG 的整段提示词/工作流文本，超长值自动截断。

## 「批量删除」不再跟着选中换脸

之前这个按钮背了三种意思：没选中时点它进入删除模式、选中了它变成蓝底「删除选中的 N 项」、模式开着又是「退出删除模式」。第二种最容易让人慌——一选中图片，它就换个颜色换行字，看着像删除模式已经被自己启动了。

- 顶部那个只管开 / 关删除模式，永远只有「批量删除」和「退出删除模式」两种样子。
- 真正删选中的文件，走网格底部那条「删除选中的 N 项」，数量也只在那里出现。
- 工具栏右侧几个按钮之间补了间距，不会再挤成一排连体按钮。

## 日记年视图看得见具体日期

以前年视图只有 12 个方块，各自写着「3 月 / 1 篇」，想知道哪天写过东西还得挨个月点进去。

- 每个月里直接画出 42 格迷你日历，有回忆的日期点亮，今天带一圈描边。
- 点某一天直接跳到那天的月视图，点月份空白处进那个月的日历。
- 年视图时左栏自动变宽，把右侧的空白借过来——12 个月一屏放得下，不用滚。
- 「年视图 / 月视图」按钮挪到了左上角「日记 共 N 篇」旁边，不再飞在窗口另一头跟「写一篇」作伴。

## 密码窗不再自我拆台

设置私密空间密码时，原来的对话框用一大段话解释「这只是防顺手的门、挡不住能操作电脑的人、删掉数据库里那行就失效」。话是真的，但放在用户正要保护自己的那一刻说，等于告诉人家这功能没用。

- 密码窗（设置、解锁、修改、取消四种形态）只留必要信息（至少 4 位、不存明文），并指明细节在哪看。
- 解锁窗现在只有一句「解锁后才能看到保险箱里的内容」——以前那句「文件没加密、直接去 Vault 文件夹拷出来」已经撤掉，摆在这儿等于告诉正在保护自己的人「这没用」。
- 完整说明搬到「设置 → 系统集成 → 私密空间的安全性」：能防什么、文件藏在哪、忘了密码怎么办、真要防取证该用什么工具。

## 桌面图标不再误报「程序已删除」

设置页曾经对着一个指向 `dist` 里旧版本的图标说「那儿已经没有程序了」——其实双击就能打开。原因是判据写成了「必须等于当前正在运行的 exe」，从开发目录启动时必然对不上。

- 判据改成「指向一份真实存在的本程序」。
- 开发目录启动时，图标自愈会按文件版本号挑最新的发布包，而不是指进 `bin\Debug`（那里一清理就废），也不会把图标指回安装目录里的旧版本。

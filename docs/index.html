它只做一件事：
把散落的东西收回来

不是又一个资源管理器，也不是又一个看图王。它解决的是「我知道那张照片在我某个盘里，但找不到」。

一个库，管完所有盘

加上文件夹就自动扫描建缩略图，C 盘、D 盘、移动硬盘混在一个墙里。按日期、类型、收藏筛，不用记路径。

图片编辑，就地改

裁剪拉直、调色滤镜、文字标注、马赛克打码、平铺水印。右栏按用途分七类，一次只展开一个面板。

视频不只是能看

内置 FFmpeg 抽封面、LibVLC 做播放，缩略图墙里直接点开就播，拖进度条、倍速、播完自动停。

发现页：让照片来找你

每次打开随机推一批，按 R 换一批。躺了好几年的片子，会以你没想过的方式重新出现。

私密空间：藏起来的那一摞

按 Ctrl+L 开一个独立窗口，像浏览器无痕模式但功能全齐：搜索、筛选、排序、收藏、自己建分区都能用。文件真正挪进隐藏目录，主网格、搜索、标签、发现页全查不到。密码可选、你自己决定：顶栏「🔑 设置密码」不点就一直是随点随进，点了进门前就要输；忘密码也不丢数据。

日记：把照片写成回忆

左边日历右边回忆，有内容的日期带个小圆点。一天能写多篇、每条挂多个图片视频；主界面右键「写进日记」就能把选中的照片塞进去。年视图一眼看完 12 个月哪天写过、写了多少，点月份直接跳过去。只存在你自己的库里。

极简模式：只留入口

设置里一个开关，隐藏未分类、最近查看、最近删除、日记、私密空间和整个「分类」分组，只留发现 / 全部媒体 / 收藏 / 文件夹 / 标签。只影响入口，一个文件都不会动，随时关回来。

收藏、分类、标签、备注

单键 F 收藏、1~5 打星，中文输入法下也照常生效。分类和标签都可以自己加，备注随手写。

时光机：后悔药

自动留最近 7 个备份节点。整理砸了、误删了，一键退回那一刻；备份文件坏了会直接拒绝，绝不覆盖好库。

认 79 种扩展名

v1.3.1 起不再只管图片视频，音频、文档、压缩包也能进来。类型可以多选筛选； 这几种双击时直接交给系统里装好的软件（Foobar / VS Code / WinRAR），不自带半成品预览器 —— 只有图片和视频走内置查看器。

三条规矩

功能可以慢慢加，这三条不许破。破了就不是这个软件了。

01

数据是你自己的

不登录、不上传、不统计、不带任何遥测。所有东西躺在 %LocalAppData%\MediaManager，断网照常用。 想连数据一起带走，就在 exe 旁边放个 portable.marker，它会变成便携版，数据跟着 U 盘走。

02

原图永远不改

编辑原图 → 生成 原名_edited 副本；编辑副本 → 原地更新它自己。删除默认进回收站，不是直接抹掉。 Save 不覆盖原件，是这行代码里最不能妥协的一条。

03

不确定就说不确定

做不到的不写进卖点，测过的才敢写在首页。全量编译 0 警告，274 项单元测试； 性能数字来自可以自己复跑的数据库基准（build/bench_db.py）， 以前那句拿不出证据的「十万张丝滑」，已经删了。

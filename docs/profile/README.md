## 在做的东西

### MediaManager · Windows 媒体管理器

免费、开源、纯本地无广告 —— 一个窗口管完你的图片、视频、音频、文档和压缩包。

[![最新版本](https://img.shields.io/github/v/release/3206YYY/MediaManager?label=%E6%9C%80%E6%96%B0%E7%89%88%E6%9C%AC&color=3B82F6)](https://github.com/3206YYY/MediaManager/releases)
[![Stars](https://img.shields.io/github/stars/3206YYY/MediaManager?color=3B82F6)](https://github.com/3206YYY/MediaManager/stargazers)
[![License](https://img.shields.io/github/license/3206YYY/MediaManager?color=3B82F6)](https://github.com/3206YYY/MediaManager/blob/main/LICENSE)

- **一个库装下所有盘**：图片 / 视频 / 音频 / 文档 / 压缩包，共 80 个扩展名，一次搜索一次筛选
- **让文件主动来找你**：「发现」页随机推送你还没细看的照片，而不是让你一个个文件夹翻
- **编辑不碰原图**：裁剪、调色、文字、马赛克、水印；编辑原图只生成 `_edited` 副本，原图一个字节都不动
- **时光机备份**：保留最近 7 个时间节点，随时把整个库退回去；坏的备份一律拒绝恢复
- **装完就能用**：安装包自带 .NET、FFmpeg、LibVLC，双击安装，不联网、不要管理员权限

C# / .NET 8 / WPF · MIT · [官网](https://3206yyy.github.io/MediaManager/) · [源码](https://github.com/3206YYY/MediaManager)

## 三条我自己的规矩

1. **数据是你自己的**。不上传、不统计、不要求登录；所有东西躺在你自己的硬盘里。
2. **不确定的事就说不知道**。功能没做到位，宁可在更新说明里写清楚边界，也不吹。
3. **删掉的东西要能找回**。误删进回收站、编辑只写副本、覆盖前先备份 —— 这三条不能有例外。
